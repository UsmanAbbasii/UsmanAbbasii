### 🪪 2. Electronic Identity Verification (eKYC)

Developed a web-based electronic identity verification application combining **OCR and facial comparison** to support identity verification.

- Extracts identity information from CNIC documents using OCR.
- Stores extracted information in a MySQL database.
- Compares the photograph on an identity document with a live face scan.
- Integrated the verification workflow into a Flask web application.

**Technologies:** Python · Computer Vision · OCR · Flask · MySQL

[![View Project](https://img.shields.io/badge/VIEW%20PROJECT-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/UsmanAbbasii/EKYC-using-computer-Vision-and-SQL-with-Deployment)
